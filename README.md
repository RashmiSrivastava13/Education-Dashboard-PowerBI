# Education-Dashboard-PowerBI
# 📊 District-Wise Education Performance Dashboard (Power BI)

This Power BI project analyzes district-level education data for the year 2023–24. It visualizes school infrastructure, student enrollment, gender parity, and board exam performance across districts.

## 📁 Files Included
- `Education_Dashboard.pbix`: Power BI file
- `Dashboard_Screenshots/`: Folder with visuals from the dashboard
- `Dashboard_Report.pdf`: PDF version of the dashboard
- `README.md`: Project explanation

## 📌 Key Features
- KPIs: Total Students, Pass %, Quality Index
- Visualizations: Bar charts, pie charts, performance trends
- Filters: District, Gender, School type
- Insightful comparisons between Class X & XII results

## 🎯 Tools Used
- Power BI (DAX, slicers, charts)
- Excel (data cleaning)

## 💡 What I Learned
- Building dynamic dashboards
- Creating performance KPIs
- Using DAX for pass % and quality index
- Designing for readability and storytelling
